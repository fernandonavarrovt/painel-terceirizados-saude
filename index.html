Role a tela para ver a próxima

Os dados vieram somados, sem informação por pessoa. Por isso, a cada etapa os pontos se misturam de novo: a cor de uma etapa não continua na seguinte. Assim o gráfico não sugere, por exemplo, quais mulheres são motoristas.

As vagas do contrato, uma a uma

Cada quadradinho é um posto de trabalho previsto por mês no contrato. Os azuis têm alguém trabalhando; os vazios, não. Passe o mouse (ou toque) para ver a função.

O que não foi informado

O ODSS pediu estes dados, de forma somada e sem identificar ninguém. A Prefeitura não os forneceu. Para um observatório de transparência, a ausência também é um resultado.
